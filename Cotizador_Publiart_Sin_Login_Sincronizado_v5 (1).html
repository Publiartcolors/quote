Modo de trabajoOffline

1. Crear respaldo completo

Descarga un archivo JSON que incluye cotizaciones, productos, las dos listas de precios, parámetros y PIN de administración. Guarda ese archivo en una carpeta compartida de la empresa, USB o nube corporativa.

2. Cargar respaldo en otro computador

Abre este mismo archivo HTML en el otro computador, entra aquí y selecciona el archivo JSON de respaldo. Podrás reemplazar todos los datos del equipo o combinar solo las cotizaciones importadas.

Consejo: antes de restaurar, descarga un respaldo del equipo que recibirá los datos.

3. Forma recomendada de trabajo para varios vendedores

  1. Designen un equipo o encargado como responsable del archivo maestro de cotizaciones y tarifas.
  2. Cada vendedor puede trabajar sin conexión y descargar su respaldo al finalizar el turno.
  3. El encargado importa los respaldos de cada vendedor con Combinar cotizaciones, y vuelve a descargar un respaldo consolidado.
  4. Distribuyan el respaldo consolidado a los demás equipos cuando necesiten actualizar sus historiales.
Si varios vendedores deben ver la misma cotización apenas se guarda, editar las mismas tarifas y compartir el panel de control en tiempo real, se necesita una versión con base de datos compartida (servidor o servicio en red). Un archivo HTML totalmente offline no puede sincronizar automáticamente equipos separados.
